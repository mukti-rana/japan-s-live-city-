## UI work

Before building or changing any UI in this project, read
`design-system/live-city-japan/MASTER.md` — it is the design source of truth (tokens,
typography, glass rules, motion, accessibility baseline, and anti-patterns).

If `design-system/live-city-japan/pages/<page>.md` exists for the page you are working on,
its rules override MASTER.md. Otherwise MASTER.md applies exclusively.
